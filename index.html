Planilha de cadastro

Envie o .xlsx com os dados das empresas. É obrigatória uma coluna de CNPJ; as demais colunas ficam disponíveis para impressão no carimbo.

⌘
Clique ou arraste o arquivo .xlsx aqui Somente Excel (.xlsx). O arquivo não é enviado a nenhum servidor.
⚙ configurar colunas e aparência do carimbo

Os nomes das colunas devem ser idênticos ao cabeçalho da sua planilha, inclusive acentos.

Documentos (PDF)

Envie um ou mais PDFs. Cada arquivo será lido para localizar um CNPJ e, quando necessário, o sistema fará OCR automaticamente.

▤
Clique ou arraste os PDFs aqui Vários arquivos de uma vez são aceitos.

Processar

Cada documento será conferido contra a planilha e, se identificado, receberá o carimbo digital com protocolo.

Resultado

Baixe os documentos carimbados individualmente ou tudo de uma vez, junto do relatório em CSV.
